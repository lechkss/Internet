# Internetik

# Описание проекта

Это проект, в котором с помощью  Pygame создаётся игра, связанная с теорией графов. Игрок должен выбирать два компьютера (узла в графе), между которыми нужно провести интернет. Для этого находится кратчайший путь и передаётся “сигнал”. Если на балансе недостаточно средств — нужно сыграть в игру (лабиринт), чтобы заработать деньги.

# Что реализовано
	•	Случайная генерация графа из узлов и рёбер
	•	Расчёт стоимости передачи пакета
	•	Алгоритм A* для поиска кратчайшего пути
	•	Возможность задавать “заторы” (которые увеличивают стоимость пути)
	•	Анимация перемещения пакета по маршруту
	•	Лабиринт как заработок денег

Технологии
	•	Pygame
	•	NetworkX

Как играть
	1.	На стартовом экране нажмите “Play”.
	2.	Выберите два компьютера — они подсветятся.
	3.	Если есть достаточно денег, передастся пакет.
	4.	Если нет — появится окно с просьбой пополнить баланс.
	5.	Для пополнения нужно пройти лабиринт.
	6.	Если прошли — баланс увеличится.

Дополнительная информация
	•	Каждое соединение между узлами имеет случайную стоимость.
	•	Заторы добавляют +5 к стоимости перехода.
	•	При успешной передаче средств на счету становится меньше.
	•	Мини-игра — это лабиринт, который генерируется случайно. В нём нужно дойти до цели стрелками.
